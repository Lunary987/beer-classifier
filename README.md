Beer classifier 🫀🍺🍻

классификатор пива с помощью заранее обученной модели resnet18 (из PyTorch)

Что делает проект:
По загруженному фото(download image) resnet18 определяет его марку.

ЧТОБЫ ВОСПОЛЬЗОВАТЬСЯ МОДЕЛЬЮ НУЖНО:

Скачать ваше фото(вставьте ссылку на ваш файл с изображением)
применить download(веса автом. скачиваются из Releases)
ВСЕ! Теперь модель предскажет к какой марке пива относится ваше изображение
